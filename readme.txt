== Description ==

Buildora is a bold Full Site Editing theme crafted for construction and renovation companies. Industrial charcoal and safety-orange design, quote-request hero, services grid, project galleries, process steps, animated stats, testimonials and quote CTAs — everything a builder needs to win clients online.

A clean, modern Full Site Editing (block) theme built with theme.json. Includes multiple page templates, curated block patterns, and style variations. Translation-ready and accessibility-conscious.
