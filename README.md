# Buildora — Construction Block Theme

**Buildora** is a bold WordPress block theme built for construction and renovation companies. Industrial charcoal and safety-orange design, quote-request hero, services grid, project galleries, process steps, animated stats, testimonials and quote CTAs — everything a builder needs to win clients online.

## Features

- **Full Site Editing** — edit headers, footers, templates and every pixel with the block editor
- **Complete theme.json design system** — charcoal/safety-orange/concrete palette, Oswald condensed display + Inter sans, fluid type scale, spacing scale, card shadows
- **11 hand-built block patterns** — quote hero, services grid, projects gallery, process steps, stats band, testimonials, quote form, FAQ, quote CTA, contact info, about story
- **12 templates** — front page, projects, services, about, contact, page, wide page, single, archive, search, 404, index
- **"Steel" style variation** — one-click blue-grey industrial alternative
- **Motion with manners** — scroll reveals, animated stat counters, back-to-top button; all disabled under `prefers-reduced-motion`
- **Accessibility** — skip link, visible focus states, semantic landmarks, keyboard-friendly navigation
- **Translation-ready** — `buildora` text domain, `/languages` directory

## Installation

1. Download or clone this repository.
2. Copy the `buildora-construction-theme` folder into `wp-content/themes/` (rename the folder to `buildora` if you like).
3. In WordPress, go to **Appearance → Themes** and activate **Buildora**.
4. Open **Appearance → Editor** to customize templates, or insert any **Buildora** pattern from the block inserter.

No plugins required. Bundled fonts (Oswald + Inter) and photos work out of the box.
